# Noctopage — build plan and module contract

PS Vita manga + e-book reader. C, VitaSDK (in WSL), libvita2d, MuPDF (AGPL-3.0).
Title ID `NOCT00001`. Unsafe VPK (no `-s` on vita-make-fself). Extended memory
(`-d ATTRIBUTE2=12`). Screen 960×544.

Vault (design + research): `C:/Users/steve/Documents/code-vault/wiki/vita-reader/`
and `C:/Users/steve/Documents/code-vault/raw/vita-reader/` (4 research reports).

## Rules for everyone working in this tree

- C (gnu11), `-Wall -Wextra -Werror`. Files ≤ 400 lines; split before that.
- **Pure modules** (no `psp2/`, `vita2d.h`, or `mupdf` includes) live where marked
  "pure" below and are built and tested on the host by `tests/Makefile` (gcc, WSL).
  Vita-only code stays thin and calls into pure code.
- NOBORU (GPL-3.0) is a design reference only. Copy no code, no assets.
- Never modify `~/vitasdk`. Third-party code lives in `third_party/`.
- Workers decode to CPU pixel buffers; **only the main thread creates or frees
  vita2d textures**.
- No libc `printf` debugging on device: use `log_printf` (core/log), which writes
  `ux0:data/noctopage/log.txt`.

## Build

- `tools/wsl.sh <script>` style: builds run in WSL as
  `MSYS_NO_PATHCONV=1 wsl -e bash <script-file>` (never `bash -lc`, it eats exit codes).
- `make` → `build/Noctopage.vpk`. `make -C tests` → host test runner, exit non-zero on failure.
- MuPDF: `tools/build_mupdf.sh` fetches the pinned 1.26.10 source tarball (sha256
  checked) into `third_party/mupdf/src/` and builds `third_party/mupdf/vita/lib/`
  (`libmupdf.a`, `libmupdf-third.a`) and `third_party/mupdf/host/lib/` for host tests.
  It must not duplicate symbols with SDK libs the app links (freetype, harfbuzz, zlib,
  libjpeg): use the SDK's copies for those.

## Data on the device

| What | Path |
|---|---|
| App data root | `ux0:data/noctopage/` |
| Database | `ux0:data/noctopage/library.db` (SQLite amalgamation, vendored) |
| Thumbnails | `ux0:data/noctopage/thumbs/<bookid>.bin` (raw RGBA 180×270 + header) |
| Settings | `ux0:data/noctopage/settings.ini` |
| Downloads | `ux0:books/` (created if missing; also scanned) |
| Log | `ux0:data/noctopage/log.txt` |

**Book id:** 64-bit FNV-1a over (file size as 8 bytes LE ‖ first 64 KiB ‖ last 64 KiB).
Progress follows the book across moves/renames.

## Storage scan

Devices probed with `sceIoGetstat`: `ux0: uma0: ur0: imc0: grw0: xmc0:`. Full recursive
walk, depth ≤ 8, on a worker thread. Skipped top-level dirs on any device: `app patch
addcont appmeta bgdl cache license savedata sqlite temp user vd0 vs0 tai pspemu/PSP/GAME
data/noctopage/thumbs`. A folder containing ≥ 2 image files and no subfolders with
images is a "folder comic". Results go into the DB; rescans are incremental by
(path, size, mtime).

## Formats

| Kind | Extensions | Engine |
|---|---|---|
| Comic archives | cbz zip cbr rar cb7 7z cbt tar | `comic/` via libarchive |
| Folder of images | jpg jpeg png gif bmp webp (+ tif tiff via MuPDF) | `comic/` |
| Reflow books | epub mobi fb2 txt html htm xhtml | MuPDF (`doc/`) |
| Fixed layout | pdf xps oxps svg | MuPDF (`doc/`) |

Image decode: JPEG via turbojpeg with scaled decode, PNG via libpng, WebP via libwebp
(scaled), GIF/BMP/TIFF via MuPDF `fz_load_image`. Pages wider/taller than 4096 px are
tiled (`img/tiles`).

| Sidebar | 205 px wide; L/R cycle sections; sections: My Books, Catalog, History, Downloads, Settings |
